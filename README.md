# Pokédex React + Vite

Atividade 03 - Pokédex feita com React e Vite.

## Sobre o projeto

A aplicação mostra os Pokémon do arquivo `pokedex-data.json` em um carrossel (também tem a opção de ver em grade). Dá para pesquisar por nome ou número, filtrar por tipo, ordenar pelos atributos e clicar em um Pokémon pra ver os detalhes. Também tem uma aba com os treinadores e os Pokémon de cada um.

Extras:
- favoritos (ficam salvos no navegador)
- comparar dois Pokémon
- botão aleatório
- tema claro e escuro

## Como rodar

```bash
npm install
npm run dev
```

Depois é só abrir http://localhost:5173 no navegador.

## Estrutura

```text
src/
├── components/   componentes React
├── css/          estilos de cada componente
├── data/         pokedex-data.json e cores dos tipos
├── hooks/        useLocalStorage
├── App.jsx
└── main.jsx
```
